Start assessment

Scenario

01Read TICKET.md and the production log excerptspending review
02Reproduce the failure locally — the naive retry test won't do itauto check
03Fix the root cause, not the symptompending review
04Add regression coverage that would have caught thisauto check
05Open a PR using the template; answer the open product questionpending review
06Defend your diff in an AI-led technical interviewpending review

Competencies in focus

Root-cause analysis Testing Systems thinking Data safety Communication

Ground rules

  • Open a PR with the provided template when done.
  • Stay in control of your diff — you'll explain every line.
  • Hidden conditions run against your branch after submission.
  • Out of time is unassessed, not failed.
